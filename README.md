# The Million-Dollar Prompt

A standalone educational Claude Code game developed for the Code in Action course.

**Status:** Repository initialization. Application source, tests, and deployment configuration are not yet committed.

This project is independent of MCP Jeopardy. Do not reuse or modify MCP Jeopardy's GitHub repository, Cloudflare Worker, D1 database, domains, or secrets.

Planned features: 15-question virtual prize ladder, guaranteed milestones, walk-away option, 50:50, prewritten AI hints, simulated audience, skip, and optional verified results email.

No real-money prizes. Not affiliated with Anthropic.
